# VienāVietā – norādes darbam ar kodu

- Saskarnes teksti, komentāri un dokumentācija ir latviski. Koda nosaukumi (mainīgie, funkcijas, tabulas) angliski.
- Datubāzes izmaiņas: labo `src/db/schema.ts`, tad `npm run db:generate` un iesniedz jauno failu no `drizzle/`. Esošās migrācijas nelabo.
- Kopīgās vērtības (transporta veidi, īpašumu veidi, sērijas, sūdzību iemesli, limiti) glabājas `src/lib/constants.ts`. Neatkārto tās citur.
- Cenas glabājas veselos eiro (`integer`). Maksājumu summas centos (`amount_cents`).
- Pirms commit: `npm run typecheck` un `npm run build`.
- Plāns un statuss: `docs/ROADMAP.md`. Pabeigtos punktus atzīmē tur.
- Citu portālu sludinājumi: 2026-11-07 lietotājs apstiprināja, ka jurists atļāvis ņemt ss.com lapas. Ievākšana: `src/lib/importers/ss-pages.ts` (sadaļas `SS_SECTIONS`, fona plānotājs `ss-scheduler.ts`, izslēdz ar `SS_CRAWL=off`). Lasām tikai sarakstu tabulas: faktus (marka, gads, cena, platība, vieta) un saiti; virsrakstu veidojam paši; pārdevēja tekstu neņemam; sludinājumu lapas neņemam, izņemot transportu: katru ss.com auto/moto sludinājuma lapu atveram vienu reizi un nolasām tikai lauku "Vieta" pilsētai (lietotājs apstiprināja 2026-11-07; `ss-details.ts`, izslēdz ar `SS_DETAILS=off`) (saraksta teksta sākumu lasām tikai, lai atpazītu modeli, ja ss.com norādīts "Citi"; to neglabājam). ss.com markas/modeļi tiek pārvērsti uz mūsu katalogu (`findMake`, `matchModel`: "Mercedes" → Mercedes-Benz, BMW "320" → 3. sērija, "E220" → E klase). Bildes: tikai saraksta sīktēla adrese (`external_thumb_url`), ko pārlūks ielādē tieši no ss.com servera ar norādi "Foto: ss.com"; bildes neglabājam un nelejupielādējam (izslēdz ar `EXTERNAL_THUMBS=off`). Pieprasījumi lēni (`SS_REQUEST_DELAY_MS`), ievērojot robots.txt. Saites uz oriģinālu: jaunā cilnē, `rel="nofollow noopener noreferrer"`, avots norādīts. Lietotājs 2026-11-07: jurista atļauja attiecas uz visiem portāliem. Tomēr neapiet robotu pārbaudes (Cloudflare, reCAPTCHA u.c.) un neizmanto portālu iekšējos API; AllePal/BCG portāli (auto24.lv, city24.lv, autoplius.lt, aruodas.lt): auto24 robots.txt bloķē AI robotus pēc nosaukuma; city24 robots.txt ievākšanu neaizliedz, bet sludinājumi ir tikai iekšējā API ar reCAPTCHA, ko neizmantojam; tiem ceļš ir partneru datu plūsma. reklama.lv Latvijas sludinājumu gandrīz nav; mm.lv ir robotu pārbaude.
- Pieteikšanās: `src/lib/auth.ts` (Better Auth). Serverī lietotāju iegūst ar `getCurrentUser()` / `requireUser()` no `src/lib/session.ts`, kas arī izslēdz bloķētos.
- React 19 atiestata nekontrolētus formas laukus pēc servera darbības, tāpēc formās ar kļūdu paziņojumiem lieto kontrolētus laukus.
- Sludinājumu saglabāšana: `src/app/sludinajumi/actions.ts`; validācija `src/lib/listing-input.ts`; antispam `src/lib/antispam.ts`. Bildes: `src/lib/storage.ts` (lokāli vai S3) un `src/lib/images.ts`.
- Antispam pārbauda, vai forma aizpildīta ne ātrāk kā 4 s pēc lapas atvēršanas; automātiskajos testos pirms iesniegšanas jāpagaida.
- Meklēšana: parametri un SQL `src/lib/search.ts` (parseSearch → conditions); filtru UI `src/components/search-filters.tsx`; karte `src/components/search-map.tsx`. Jaunu filtru pievieno visās trijās vietās.
- `getCurrentUser()` sauc `headers()` ārpus try/catch un `unstable_rethrow`, lai neapklusinātu Next dinamiskās renderēšanas signālus.
- Bilžu krātuve: `STORAGE_DRIVER` = s3 | db | local; startējot `src/instrumentation.ts` pārbauda krātuvi un ieraksta rezultātu žurnālā.
- Sludinājumu vēsture: `price_history` glabā cenu no katra izmaiņas brīža (arī sākuma cenu); `listings.first_price` = sākuma cena, ja cena mainīta (kārtošanai "Lielākais cenu kritums"). Lapas `/cenu-kritumi`, `/vesture`; loģika `src/lib/history.ts`.
- VZD darījumi: `src/lib/importers/vzd.ts` ielādē data.gov.lv „Darījumi ar telpu grupām” (CC BY 4.0; failu saites no CKAN API, jo nosaukumi mainās) tabulā `vzd_deals`; vaicājumi `src/lib/vzd.ts`; atsauce uz avotu obligāta. Izslēdz ar `VZD_IMPORT=off`.
